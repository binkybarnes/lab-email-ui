  This kills the "Phase 2 priority > Phase 1 > Phase 3" rule. Instead, every
  candidate is judged on its own evidence, not on which source found it. If

  - This means a Brave hit on e.g. bioengineering.ucsd.edu/faculty/jones (dept

● Short answer: no first-party sync. Conversation history is plain JSONL files
  at ~/.claude/projects/<project>/<session-id>.jsonl on disk.

  Practical paths:
  - Rsync / Dropbox / iCloud on ~/.claude/ between the two machines. The catch:
  the project path has to be identical on both — Claude Code ties sessions to
  absolute disk paths, so /home/johnpork/codeing/transferhacks/lab-emailer on
  one machine won't resume from /Users/johnpork/codeing/... on another.
  - Private git repo for ~/.claude/projects/<this-project>/. Works but
  transcripts contain pasted code and command history — don't push to a public
  remote.
  - claude.ai/code (web app) keeps a separate session list — not a sync
  mechanism; it won't see your CLI sessions.

  /export dumps a transcript to plaintext but there's no import counterpart, so
  it's good for reading on another machine, not resuming on one.

  So: easiest is rsync ~/.claude/ + ensure the project lives at the same
  absolute path on both computers.
